iCreate3

An iRobot iCreate3 with a 2D lidar and a Raspberry Pi running EasyNav on ROS 2 Kilted, navigating in a house with the Costmap stack. This page gathers its hardware, its EasyNav parameter files (one per controller: RPP, MPPI and MPC) and its launchers. To set up the robot, build the map and deploy EasyNav on it, see Deploying EasyNav on a Real iCreate3 Robot.

Hardware

Component

Details

Base

iRobot iCreate3, with the ROS 2 Iron firmware with Fast DDS (https://edu.irobot.com/create3-latest-fw).

Lidar

RPLidar S2 mounted on top of the base, connected to the Raspberry Pi via USB (driver: sllidar_ros2).

On-board computer

Raspberry Pi 4 Model B powered from the base via USB-C, with Ubuntu 24.04 Desktop and ROS 2 Kilted. It communicates with the base and the laptop over Wi-Fi.

Operator laptop

Runs rviz2 and connects to the Raspberry Pi via SSH to launch processes.

The parameter files and launchers live in a package of the robot, easynav_indoor_testcase, together with the map of the house (maps/casa.yaml). There is one launcher per controller:

Each of them includes easynav_icreate3.launch.yaml, which starts the lidar driver (sllidar_s2_launch.py), the static transform from base_link to laser and EasyNav. On the Raspberry Pi:

Things specific to this robot

  • Limits and geometry. The iCreate3 tops out at 0.306 m/s: robot_limits caps the linear velocity at 0.3 m/s. robot_geometry is a circle of 0.17 m radius.

  • Odometry. The base publishes the odom → base_link transform, which AMCL reads (compute_odom_from_tf: true).

  • Lidar. The laser has no group: the localizer and the obstacle filter only use the point perceptions without one.

  • Localization. With the dense S2 scan on a real map, the AMCL match_score is around 0.33 even when well localized, so match_threshold is 0.2 in amcl_convergence and amcl_relocalize (the same value in both). AMCL uses 300 particles and may inject up to 10% of random particles (random_particles_max_fraction) to escape a wrong pose.

  • Clocks. The Raspberry Pi has no battery-backed clock: keep it synchronized with NTP (for example systemd-timesyncd). A clock offset with the base places the scans with a stale transform, and AMCL gets lost as soon as the robot moves.

  • Laptop. Use the same ROS 2 distribution as the robot on the laptop: some message types are not exchanged between different Fast DDS versions (for example Kilted and Rolling).

controller_node:
  ros__parameters:
    use_sim_time: false
    # Create 3 tops out at 0.306 m/s; the velocity smoother enforces these on every command
    robot_limits:
      max_linear_vel: 0.3
      min_linear_vel: -0.1
      max_angular_vel: 1.0
      max_linear_acc: 0.5
      max_linear_decel: 0.8
      max_angular_acc: 2.0
      max_angular_decel: 2.0
    controller_types: [rpp]
    rpp:
      rt_freq: 30.0
      plugin: easynav_regulated_pp_controller/RegulatedPurePursuitController
      safety_margin: 0.05
      use_dynamic_window: false
      allow_reversing: false
      lookahead_dist: 0.3
      min_lookahead_dist: 0.2
      max_lookahead_dist: 0.5
      lookahead_time: 1.5
      use_velocity_scaled_lookahead_dist: true
      use_rotate_to_heading: true
      rotate_to_heading_angular_vel: 0.8
      rotate_to_heading_min_angle: 0.785
      use_regulated_linear_velocity_scaling: true
      regulated_linear_scaling_min_radius: 0.6
      regulated_linear_scaling_min_speed: 0.1
      use_fixed_curvature_lookahead: false
      curvature_lookahead_dist: 0.6
      interpolate_curvature_after_goal: false
      use_obstacle_regulated_linear_velocity_scaling: true
      obstacle_scaling_dist: 0.3
      obstacle_scaling_gain: 0.8
      min_approach_linear_velocity: 0.05
      approach_velocity_scaling_dist: 0.4
      xy_goal_tolerance: 0.1
      yaw_goal_tolerance: 0.105

localizer_node:
  ros__parameters:
    use_sim_time: false
    localizer_types: [costmap]
    costmap:
      rt_freq: 50.0
      freq: 5.0
      reseed_freq: 1.0
      plugin: easynav_costmap_localizer/AMCLLocalizer
      compute_odom_from_tf: true
      num_particles: 300
      # Random particles when the scan match drops: lets AMCL escape a wrong pose
      random_particles_max_fraction: 0.1
      noise_translation: 0.05
      noise_rotation: 0.1
      noise_translation_to_rotation: 0.1
      initial_pose:
        x: 0.0
        y: 0.0
        yaw: 0.0
        std_dev_xy: 0.1
        std_dev_yaw: 0.01

maps_manager_node:
  ros__parameters:
    use_sim_time: false
    map_types: [costmap]
    costmap:
      freq: 10.0
      plugin: easynav_costmap_maps_manager/CostmapMapsManager
      package: easynav_indoor_testcase
      map_path_file: maps/casa.yaml
      filters: [obstacles, inflation]
      obstacles:
        plugin: easynav_costmap_maps_manager/CostmapMapsManager/ObstaclesFilter
      inflation:
        plugin: easynav_costmap_maps_manager/CostmapMapsManager/InflationFilter
        inflation_radius: 1.3
        cost_scaling_factor: 3.0

planner_node:
  ros__parameters:
    use_sim_time: false
    planner_types: [simple]
    simple:
      freq: 1.0
      plugin: easynav_costmap_planner/CostmapPlanner
      cost_factor: 10.0
      continuous_replan: true

sensors_node:
  ros__parameters:
    use_sim_time: false
    forget_time: 0.5
    sensors: [laser1]
    perception_default_frame: odom
    laser1:
      topic: scan
      type: sensor_msgs/msg/LaserScan

system_node:
  ros__parameters:
    use_sim_time: false
    use_real_time: true
    robot_frame: base_link
    # iRobot Create 3: 339 mm diameter, circular base
    robot_geometry:
      radius: 0.17
      inscribed_radius: 0.17
      height: 0.35
    position_tolerance: 0.15
    angle_tolerance: 0.15

recovery_node:
  ros__parameters:
    use_sim_time: false
    recovery_manager:
      plugin: easynav_diagnostic_recovery/DiagnosticRecoveryManager
      # Level-0: stop on imminent collision, whoever produced cmd_vel
      safety_reflex_types: [collision]
      collision:
        plugin: easynav_diagnostic_recovery/CollisionSafetyReflex
        debug_markers: true
        downsample_leaf_size: 0.05
        brake_acc: 0.8
        safety_margin: 0.05
      # Level-1: evaluators diagnose, mitigations tried by priority (lower first)
      evaluator_types: [no_path, obstacle_close, controller_stuck, amcl_convergence, ros_graph]
      no_path:
        plugin: easynav_diagnostic_recovery/NoPathEvaluator
      obstacle_close:
        plugin: easynav_diagnostic_recovery/ObstacleTooCloseEvaluator
        safe_distance: 0.22         # 0.17 m body radius + 0.05 m
        debounce_duration: 0.5
      controller_stuck:
        plugin: easynav_diagnostic_recovery/ControllerStuckEvaluator
        linear_velocity_threshold: 0.02
        progress_distance_threshold: 0.05
        stuck_time_threshold: 3.0
      amcl_convergence:
        plugin: easynav_costmap_localizer/AmclConvergenceEvaluator
        covariance_threshold: 1.0
        match_threshold: 0.2        # well localized ~0.33 with the S2, lost ~0.10
      ros_graph:
        plugin: easynav_diagnostic_recovery/RosGraphEvaluator
        freq: 1.0
        startup_grace: 15.0
        error_debounce: 2.0
        ignored_topics: ["goal_pose", "initialpose", "incoming_map", "incoming_occ_map", "incoming_pc2_map"]
        ignored_consumers: ["easynav_tui_*", "_ros2cli*"]
      mitigation_types: [retreat, amcl_relocalize, advance, shutdown, human_assistance, cancel_mission]
      retreat:
        plugin: easynav_diagnostic_recovery/SafeRetreatRecovery
        priority: 10
        safe_distance: 0.35         # > obstacle_close.safe_distance
        retreat_speed: 0.08
      amcl_relocalize:
        plugin: easynav_costmap_localizer/AmclRelocalizeMitigation
        priority: 10
        covariance_threshold: 1.0
        match_threshold: 0.2        # same as amcl_convergence
      advance:
        plugin: easynav_diagnostic_recovery/AdvanceRecovery
        priority: 10
        advance_distance: 0.3
        advance_speed: 0.08
        escalate_after: 15.0
        episode_gap: 10.0
      shutdown:
        plugin: easynav_diagnostic_recovery/ShutdownRecovery
        priority: 100
        handled_hardware_ids: ["ros_graph"]
      human_assistance:
        plugin: easynav_diagnostic_recovery/HumanAssistanceRecovery
        priority: 1000
        timeout: 30.0
        ignored_hardware_ids: ["ros_graph"]
      cancel_mission:
        plugin: easynav_diagnostic_recovery/CancelMissionRecovery
        priority: 2000

# iCreate3 + RPLIDAR S2 + EasyNav. The easynav_icreate3_<controller>.launch.yaml
# files include this one with their own params_file.

launch:
- arg:
    name: params_file
    default: $(find-pkg-share easynav_indoor_testcase)/robots_params/icreate3.costmap.rpp.params.yaml
    description: EasyNav ROS 2 parameters file
- arg: {name: lidar, default: 'true', description: Start the RPLIDAR S2 driver}
- arg: {name: serial_port, default: /dev/ttyUSB0, description: RPLIDAR serial port}
- arg: {name: laser_frame, default: laser, description: RPLIDAR frame_id}
- arg: {name: laser_tf, default: 'true', description: Publish the static base_link -> laser TF}
- arg: {name: laser_x, default: '0.02', description: Laser x in base_link (m)}
- arg: {name: laser_y, default: '0.0', description: Laser y in base_link (m)}
- arg: {name: laser_z, default: '0.22', description: Laser z in base_link (m)}
- arg: {name: laser_yaw, default: '3.14', description: Laser yaw in base_link (rad)}

- include:
    if: $(var lidar)
    file: $(find-pkg-share sllidar_ros2)/launch/sllidar_s2_launch.py
    arg:
    - {name: serial_port, value: $(var serial_port)}
    - {name: frame_id, value: $(var laser_frame)}

- node:
    if: $(var laser_tf)
    pkg: tf2_ros
    exec: static_transform_publisher
    name: base_to_laser_tf
    args: >-
      --x $(var laser_x) --y $(var laser_y) --z $(var laser_z) --yaw $(var laser_yaw)
      --frame-id base_link --child-frame-id $(var laser_frame)

- node:
    pkg: easynav_system
    exec: system_main
    output: screen
    on_exit: shutdown
    param:
    - from: $(var params_file)
