    Playgrounds and Robots¶

    EasyNav comes with ready-to-run configurations for simulated robots, the PlayGrounds, and for real robots.

    Playgrounds¶

    The PlayGrounds are complete Gazebo Harmonic simulations integrated with EasyNav: a robot, its world, the maps and ready-to-run EasyNav configurations. They all live in one repository, easynav_playgrounds, and each configuration is a launch file that starts Gazebo, the robot, EasyNav and RViz2.

    Each PlayGround is split in three packages, so that the robot model and the simulation can be used without EasyNav:

    Package

    Contents

    easynav_playground_<robot>_description

    The robot model: URDF, meshes and controllers. Neither Gazebo nor EasyNav.

    easynav_playground_<robot>_worlds

    The Gazebo simulation: worlds, their maps, and the launchers that spawn the robot (gazebo_sim.launch.yaml starts Gazebo and the robot). No EasyNav.

    easynav_playground_<robot>

    The EasyNav configurations (params/) and launchers (easynav_*.launch.yaml).

    Note

    The PlayGrounds need Gazebo Harmonic or newer, so they run on Jazzy and later distributions, but not on Humble, whose Gazebo is Fortress. EasyNav itself (core and plugins) does run on Humble: only these simulations do not.

    They are the reference configurations of EasyNav: the HowTos (HowTos and Practical Guides) and the Getting Started guide use them, and they are a good starting point for your own robot’s parameter file.

    PlayGround

    Robot and world

    Configurations

    Kobuki PlayGround (indoor reference)

    Turtlebot2 (Kobuki) in a small house

    Costmap (RPP, MPPI, MPC, SeReST, MH-AMCL, routes, safety mode), Simple, mapping, multirobot

    Summit PlayGround (outdoor reference)

    Robotnik Summit XL in an outdoor excavation and in an indoor warehouse

    NavMap and Bonxai (RPP, MPPI, MPC), GPS fusion, warehouse logistics

    TIAGo PlayGround

    PAL Robotics’ TIAGo and TIAGo Pro (holonomic) in a small house

    Costmap with RPP; NavMap and Bonxai with NavMap AMCL; TIAGo Pro with holonomic MPPI

    Omni PlayGround

    Three- to six-wheel omnidirectional robots in two mazes

    Costmap with holonomic MPPI, in each heading mode

    Ackermann PlayGround

    Toyota Prius (Ackermann steering) on the Sonoma Raceway

    NavMap with RPP or Ackermann MPC, GPS fusion

    Aerial PlayGround

    A UFO (x, y, z, yaw) in a town

    Bonxai 3D planner, aerial MPC, GPS fusion, 3D goals

    Marine PlayGround

    A boat (WAM-V) and a submarine (Tethys LRAUV) in a synthetic sea

    Submarine: Bonxai 3D planner under the water, MPC, dead reckoning (IMU, DVL, depth gauge); boat and submarine sensors, imaging sonar, waves

    See Installation to install them.

    Real robots¶

    EasyNav runs on real robots with the same parameter files: change the sensor topics, the robot’s geometry and limits, and the map. See:

    • iCreate3 — the configurations and launchers of an iRobot iCreate3 with a 2D lidar.

    • Deploying EasyNav on a Real iCreate3 Robot — how to deploy EasyNav on that iCreate3.

    • TIAGo — the configurations and launchers of a PAL TIAGo, with EasyNav built on ROS 2 Humble.

    • Migration Guide — moving a robot that runs Nav2 to EasyNav.

    • Real-time System Setup — the real-time limits EasyNav needs on the robot’s computer.
